# Fresh Ride Mobile

Marketing site for [freshridemobile.shop](https://freshridemobile.shop), a mobile auto detailing service.

## Local preview

```bash
npx serve .
```

The site is dependency-free HTML, CSS, and JavaScript and deploys directly to Vercel.
